## 📸 How to Use

1. **Upload a Photo**
   - Click "📁 Upload Image" or "📷 Use Camera"
   - Select a product photo

2. **Enhance the Image**
   - Click "✨ Enhance Image"
   - See the before/after comparison

3. **Generate AI Content**
   - Click "🔍 Generate with AI"
   - Watch as AI creates:
     - Product title
     - Description
     - Price suggestion

4. **Review & Edit**
   - Edit any field as needed
   - Adjust price, title, or description

5. **Publish to Square**
   - Click "🚀 Create Square Listing"
   - Get confirmation with Item ID
   - Check your Square Dashboard!

## 🆘 Troubleshooting

### Server Issues
- **Port already in use**: Kill any process on port 3001
- **API keys not working**: Check the .env file was created correctly

### Client Issues
- **Blank page**: Check browser console for errors
- **Can't connect to server**: Make sure server is running on port 3001

### Camera Issues
- **Camera not working**: Try "Upload Image" instead
- **Need HTTPS**: Camera works on localhost without HTTPS
